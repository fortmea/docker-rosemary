Docker, natively, on your Redmi Note 10S

The official Docker Engine and Docker Compose running on the Xiaomi rosemary (Helio G95 / MT6785) with LineageOS and root. No Termux, no chroot, no virtual machine.

Download Installation guide

Install with MMRL

In MMRL, open Repositories → Add and paste this URL. The Docker module shows up in the list, and MMRL handles installs and updates.

The Magisk app also updates the module on its own once it is installed.

Get started

  1. Flash a Docker-ready kernel

    Stock LineageOS lacks six options Docker needs. Every release ships a prebuilt kernel (rosemary-docker-Image.gz) that you swap into your own boot image. Kernel guide

  2. Install the module

    From MMRL, or download the zip and install it in Magisk → Modules. The installer checks the kernel and refuses incompatible ones.

  3. Reboot and run

    Docker starts on boot. Open a root shell and use it like on any Linux machine.

su
dockerctl status
docker run --rm hello-world
docker compose up -d

How it works

Own mount namespace

dockerd runs in a private namespace with a writable /run and /etc. Android's own filesystem is left untouched.

Policy routing and DNS

Rules for Docker's address pool follow the active Wi-Fi or mobile connection, and DNS follows the current network.

eBPF firewall aware

docker-uidfw lets container users through Android's per-UID firewall, never installed apps.

Hotspot keeps working

Docker does not change the FORWARD policy, so tethering and the hotspot are unaffected.

Official binaries

Static builds from download.docker.com and Docker Compose releases, with pinned SHA-256.

Plays well with others

Docker's networks skip the Droidspaces range, so both can run side by side.

Requirements and limits

You need

  • Redmi Note 10S / Poco M5s (rosemary)
  • Unlocked bootloader and LineageOS 24
  • Magisk (KernelSU and APatch are detected)
  • ~250 MB plus space for your images

Good to know

  • arm64 images only (no amd64 emulation)
  • No Swarm or overlay networks
  • LineageOS updates replace the kernel: flash it again afterwards
  • Always keep a backup of your boot image
